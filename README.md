### What is this? 
This is a course of IoT-tech and micro-controllers in smart-systems.  

In this repo we log the process in the commit log, as well as the code. 


### Why?
It is part of the information technology and information systems programme offered at University of South-Eastern Norway.

Having a repo to look back to is a good way to actually log stuff because the commit messages can be small, but many. 

This way we can avoid writing a separate more extensive log. Which tends to be done more seldom anyway. 

### Who is it for?
Mainly for the course participants, as well as the course lecturer to be able to assess the process. Others are welcome to fork and clone, but be warned, this is a student project. We could probably do some stuff in better ways.
